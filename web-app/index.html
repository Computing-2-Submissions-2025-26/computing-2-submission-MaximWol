How to Play

  • The Code Setter picks a secret code of 4 colours from the 6 available. Repeats are allowed.
  • The Code Breaker has 10 attempts to guess the exact code.
  • After each guess, pegs are awarded:
  • Black peg: correct colour in the correct position.
  • White peg: correct colour in the wrong position.
  • The Breaker wins by scoring 4 black pegs. They lose if all 10 attempts run out.
